## 1. Qué resuelve

RF-46: la búsqueda semántica del corpus aprobado para Warren AI, expuesta como REST:

- `POST /v1/rag/buscar` — embed de la consulta → índice con filtros de metadata (RF-45)
  → hidratación por D1 → fragmentos con **cita completa obligatoria** (definición de
  hecho #2 del rol), score vigente (RF-12/RF-17) y similitud.
- `GET /v1/rag/working-set` — el ÚLTIMO working set materializado en
  `[identificador interno]` (lo escribirá P4 con `[función interna]()`), hidratado en el
  orden guardado (el ranking del set).

Registradas en `[ruta interna]`: heredan auth Bearer + limitador. La búsqueda **no exige
scope write** — la clave read de Warren alcanza.

## 2. Decisiones

| # | Tema | Decisión |
|---|---|---|
| 1 | Traducción de filtros (RF-45) | `symbols` → `simbolo {$in}`, `min_level` → `nivel {$gte}` (índice 0-4), `from`/`to` → `fecha {$gte/$lte}` epoch seg, `sources` → `fuente {$in}`, `origin` → `origen {$eq}`, `categories` → `cats {$in}` de máscaras precomputadas con `BITS_CATEGORIA` |
| 2 | Filtro de categorías | Exigir S categorías ⇒ `2^(8-|S|)` máscaras que contienen TODOS los bits (`[función interna]()`). Si el `$in` supera `[identificador interno]` (100) O el índice lo rechaza en runtime → **reintento sin el filtro de cats + post-filtro exacto en D1** por las categorías REALES del score (fuente de verdad), recuperando `top_k×4` (tope 50). P3 no queda rehén del límite empírico del `$in` |
| 3 | RF-51 también AL LEER | La hidratación exige `[campo interno]='approved'`: un vector sobreviviente de un ítem descartado jamás sale (defensa en profundidad junto al candado de escritura de P2) |
| 4 | Huérfanos | Un vector sin fila D1 se salta (contado en el log `[código interno]`) sin tumbar la consulta |
| 5 | Errores | 503 `[código interno]` (sin bindings), 503 `[código interno]`/`[código interno]`, 503 `[código interno]` (índice caído, incluso tras el reintento), 400 `validation_error`, 404 si nunca hubo working set |
| 6 | Similitud | Clamp defensivo a [0,1] antes de devolverla (contrato `[función interna]`) |
| 7 | Metadata del índice | NO se pide en la query (`[función interna]: "none"`): todo lo que la respuesta necesita vive en D1 (cita completa + score); el índice solo ordena por similitud |
| 8 | Working set | Lee la última fila por `[campo interno]`; ids inexistentes se omiten sin romper el set; tope 100 ítems (RF-47) por si una fila vieja quedó fuera de contrato |
